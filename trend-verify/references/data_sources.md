# 数据源目录

本文件列出趋势验证所需的所有数据源及其 URL 模式。

> **CDP 实操经验与反爬应对详见 `references/cdp_search_strategy.md`**。本文件只列静态 URL 模式；搜索引擎降级顺序、反爬触发应对、evaluate_script 模板等动态策略统一在那里维护。

---

## 工具策略：gmapi 优先 + CDP 补充

**Step 0' 已通过 gmapi 批量拉硬数据**（详见 `templates/gmapi_data_package.md`），CDP 阶段只需补 `fallback_needed` 清单中的文本类证据。

| 数据类型 | 首选 | 说明 |
|---------|------|------|
| 龙虎榜异动/营业部明细 | **gmapi** | `sales_depts` 已含机构/北向自动分类 |
| 个股资金流 | **gmapi** | `money_flow` 含五档 |
| 板块成分股 + 共振判定 | **gmapi** | `sector_resonance` 已自动算 |
| 历史 K 线 + 涨停判定 | **gmapi** | `history` 含 is_limit_up 精确判定 |
| 业绩预告 | **gmapi** | `finance_forecast` 含业务说明 |
| 公司异动公告/概念否认 | **CDP**（必查） | gmapi 不覆盖公告文本 |
| 新闻标题概念词 | **CDP**（必查） | gmapi 无新闻接口 |
| 问询函/关注函/停牌核查 | **CDP**（必查） | gmapi 无监管函件 |
| 行业基本面数据（1.2b） | **CDP** 行业平台 | 仅当板块共振触发 |
| 历史相似案例库 | **CDP** 搜索引擎 | gmapi 有 K线但无事件标注 |

**CDP 访问规则**：
- 定向数据访问 → CDP 直接访问对应 URL
- 广域搜索（历史案例、监管信息等）→ CDP 打开 Google（`https://www.google.com/search?q={关键词}`）或百度（`https://www.baidu.com/s?wd={关键词}`）
- WebReader 不支持中文 URL，不适用于国内数据源

**完整字段映射与判定阈值**见 `gmapi_to_trend_verify_mapping.md`。

## 公司公告

### 巨潮资讯网（cninfo.com.cn）
- **用途**：查询公司异动公告、否认/确认公告
- **URL模式（个股披露页，推荐）**：`http://www.cninfo.com.cn/new/disclosure/stock?stockCode={代码}&orgId={orgId}`
  - 沪市 orgId：`gssh0{代码}`（如 600141 → gssh0600141）
  - 深市 orgId：`gssz0{代码}`
- **URL模式（搜索）**：`http://www.cninfo.com.cn/new/fulltextSearch?searchkey={股票名称}&sdate={开始日期}&edate={结束日期}`
- **获取方式**：CDP（页面需动态渲染）
- **注意**：
  - 搜索关键词用股票名称（如"兴发集团"），非代码
  - **公告详情页是 PDF 渲染**，无法用 evaluate_script 直接提取文本。需要查正文时改用下方东方财富公告详情页

### 东方财富个股公告（公告正文文本获取）
- **用途**：辅助查询公司公告；**获取公告正文文本（替代巨潮 PDF）**
- **URL模式（个股公告列表）**：`https://data.eastmoney.com/notices/stock/{代码}.html`
- **URL模式（公告搜索）**：`https://so.eastmoney.com/ann/s?keyword={代码}+{名称}+{关键词}`
- **URL模式（公告详情，含正文文本）**：`https://data.eastmoney.com/notices/detail/{代码}/{AN编号}.html`
  - AN 编号格式如 `AN202606151823570139`
  - 通过公告搜索页获取 AN 编号
  - **页面 `body.innerText` 直接包含完整公告正文**，无需下载 PDF
- **获取方式**：CDP
- **实操技巧**：东财公告详情页侧边栏同时显示龙虎榜、股东研究、研报、十大股东、核心题材 — 一次访问可覆盖多项数据需求

## 行业专业数据平台

以下平台按行业分类，用于 1.2b 板块逻辑验证时获取行业基本面数据。**东财是证券平台，行业基本面数据不是它的强项，必须优先使用行业专业平台。**

### 化工行业

#### 卓创资讯（sci99.com）
- **用途**：化工/能源/塑料/橡胶等大宗商品价格、开工率、装置动态、周评月评
- **产品页**：`https://ochem.sci99.com/product/{产品拼音缩写}`
  - 常见产品映射：环氧丙烷=po、苯乙烯=sm、甲醇=meoh、丙烯=C3、乙烯=C2
- **搜索**：`https://www.sci99.com/search.html?keyword={关键词}`
- **获取方式**：CDP
- **关键数据**：日度价格评估报告、企业报价动态、装置停检动态、周评/月评分析、开工负荷率、进出口数据

### 有色金属

#### 上海有色网（smm.cn）
- **用途**：有色金属（铜、铝、锂、镍、锌等）价格、库存、开工率
- **URL模式**：`https://www.smm.cn/{金属品种}`
- **获取方式**：CDP
- **关键数据**：现货价格、期货价格、社会库存、冶炼厂开工率、进出口数据

### 钢铁/黑色系

#### 我的钢铁网（mysteel.com）
- **用途**：钢铁、铁矿石、焦炭等黑色系价格、库存、产量数据
- **获取方式**：CDP
- **关键数据**：钢材价格指数、社会库存、高炉开工率、铁矿石港口库存

### 新能源/新材料

#### 百川盈孚（baiinfo.com）
- **用途**：化工、新能源（光伏、锂电、风电）、新材料等产业链数据
- **获取方式**：CDP
- **关键数据**：产业链价格、开工率、产能、进出口

### 大宗商品综合

#### 生意社（100ppi.com）
- **用途**：大宗商品价格行情、涨跌榜、产业链数据
- **首页**：`https://www.100ppi.com/`（含每日价格变动滚动新闻）
- **分榜直达（推荐，避免从首页找）**：`https://www.100ppi.com/bai/list-{id}.html`
  - 化工：list-70
  - 能源：list-10
  - 有色：list-40
  - 钢铁：list-20
  - 建材：list-30
  - 农副：list-50
  - 橡塑：list-80
  - 纺织：list-90
- **获取方式**：CDP（无需登录，免费可达）
- **关键数据**：商品价格涨跌榜、产业链价格图谱、行业分析师文章、每日均差变化（如"黄磷6月15日均线上穿 +56.66元/吨"是关键技术突破信号）
- **优势**：相比卓创资讯（需登录），生意社免费可达且数据足够支撑板块逻辑验证

## 行业与平台映射表

根据概念所属行业类型，选择对应的首选行业平台。1.2b 板块逻辑验证时，**必须**同时搜索行业平台和证券平台。

| 行业/概念类型 | 首选行业平台 | 证券平台辅助 |
|-------------|------------|------------|
| 化工（环氧丙烷、氯碱、聚氨酯、涂料等） | 卓创资讯 | 东财新闻/研报/机构调研 |
| 有色金属（铜、铝、锂、镍、稀土等） | 上海有色网 | 东财新闻/研报/机构调研 |
| 钢铁/铁矿石/焦炭 | 我的钢铁网 | 东财新闻/研报/机构调研 |
| 新能源（光伏、锂电、风电） | 百川盈孚 / SMM | 东财新闻/研报/机构调研 |
| 大宗商品（农产品、石油、天然气） | 生意社 / 卓创资讯 | 东财新闻/研报/机构调研 |
| 科技/AI/半导体 | 东财研报 / 券商研报 | 主要依赖证券平台 |
| 消费/医药/金融 | 东财研报 / 券商研报 | 主要依赖证券平台 |

**使用规则**：
1. 识别概念所属行业 → 查上表确定首选行业平台
2. 在行业平台搜索价格/供需/产能等硬数据
3. 在东财搜索机构调研和研报作为辅助
4. 两个来源都必须搜索，才能判定"发现"或"未发现"

## 监管信息

### 深交所官网
- **用途**：查询问询函、关注函
- **URL（监管函栏目）**：`https://www.szse.cn/disclosure/listed/notice/index.html`
- **URL（首页）**：`https://www.szse.cn/`
- **获取方式**：
  - **首选**：巨潮个股披露页搜索"问询/关注/停牌"关键词（问询函通常作为公司公告发布）

  - **降级**：CDP 搜索引擎搜"{股票名称} 问询函 深交所"（百度易触发验证码，优先 Bing/360）

## 历史案例

### 搜索引擎（历史相似案例无明确目标站点，必须用搜索引擎）
- **用途**：搜索历史相似案例（N连板+概念否认）
- **搜索关键词模式**："{连板数}连板 异动公告 概念否认"、"连板股 历史走势"
- **降级顺序**（按 cdp_search_strategy.md 可靠性表）：
  1. **WebSearch MCP 工具**（配额内最优，无反爬）
  2. **CDP Bing** `https://cn.bing.com/search?q={关键词}`
  3. **CDP 360 搜索** `https://www.so.com/s?q={关键词}`
  4. **CDP 百度**（易触发反爬，最后用）
  5. **CDP Google**（需 `proxy` 开代理）
- **DOM 抓取失败应对**：用 `document.body.innerText` 整体提取，再按关键词切分（详见 cdp_search_strategy.md 第五节）
