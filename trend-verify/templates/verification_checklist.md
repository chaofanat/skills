## Layer 1：催化剂持续性（权重 40%）

### 1.1 公司确认/否认（P0，权重 20/40）

**搜索目标**：公司是否在公告中确认或否认驱动概念

**数据源**：
- 巨潮资讯：`http://www.cninfo.com.cn/new/fulltextSearch?searchkey={股票名称}&sdate={近期日期}`
- 东方财富公告：个股新闻页面筛选"公告"类型

**双假设判定**：

| 假设 | 判定标准 | 得分 |
|------|---------|------|
| H_延续 | 公司公告明确确认相关业务存在且有收入 | +20分 |
| H_延续 | 公司公告提到相关业务但未量化 | +12分 |
| H_中断 | 公司公告明确否认相关业务（"公司没有XX业务"） | -20分 |
| H_中断 | 公司公告明确否认相关收入（"未形成相关业务收入"） | -15分 |
| 中性 | 公司未发布相关公告，或公告中未提及该概念 | 0分 |

**提前停止**：若 H_中断得分 ≤ -15分，标记"催化剂坍塌"，Layer 1 直接计 0-10分。

---

### 1.2 板块共振 vs 独狼（P1，权重 10/40）

**搜索目标**：同概念板块内是否有3只以上个股同步上涨

**数据源**：
- 东方财富板块行情：搜索概念名称，查看板块个股涨幅
- 东方财富概念板块页面

**双假设判定**：

| 假设 | 判定标准 | 得分 |
|------|---------|------|
| H_延续 | 同概念板块3只以上个股当日涨幅>3% | +10分 |
| H_延续 | 同概念板块2只个股当日涨幅>3% | +6分 |
| H_中断 | 目标个股独涨，同板块其他个股下跌或微涨(<1%) | -10分 |
| 中性 | 板块表现分化，部分涨部分跌 | 0分 |

---

### 1.2b 概念板块趋势逻辑验证（P1，条件触发，调整 1.2 得分）

**触发条件**：仅当 1.2 判定为板块共振（H_延续得分 ≥ +6）时执行。若 1.2 判定为独狼，跳过本节。

**目的**：板块共振说明多只个股在同步上涨，但共振能否持续取决于背后的驱动逻辑是否成立。本节独立搜索板块层面的驱动叙事，验证逻辑链是否仍然坚实。

---

#### 1.2b-1 逻辑发现

**搜索目标**：独立搜索板块/行业层面的驱动叙事（不依赖 Step 0 的个股概念结果）

**数据源选择策略**：

**第一步：识别行业类型**。根据概念名称判断所属行业，然后按 `references/data_sources.md` 中的"行业与平台映射表"选择首选行业平台。

**第二步：搜索行业专业平台**（必须执行，不可跳过）：
- 化工类 → 卓创资讯：`https://www.sci99.com/search.html?keyword={概念名称}` 或产品页 `https://ochem.sci99.com/product/{产品缩写}`
- 有色金属类 → 上海有色网：`https://www.smm.cn/{品种}`
- 钢铁类 → 我的钢铁网：`https://www.mysteel.com/`
- 新能源/新材料类 → 百川盈孚：`https://www.baiinfo.com/`
- 大宗商品综合 → 生意社：`https://www.100ppi.com/`

**第三步：搜索证券平台**（补充验证）：
- 东方财富新闻搜索：`https://so.eastmoney.com/news/s?keyword={概念名称}+板块+行业`，提取板块级行业叙事和政策动态
- 东方财富机构调研：查看板块龙头公司的机构调研记录，提取行业观点
- 东方财富概念板块页面：查看板块内个股涨幅分布，识别板块龙头
- 巨潮资讯龙头公告：`http://www.cninfo.com.cn/new/fulltextSearch?searchkey={龙头公司名称}`，验证龙头公司是否在公告中确认产业逻辑

**两个来源都必须搜索，才能判定"发现"或"未发现"。仅搜索证券平台不得判定行业数据"未发现"。**

**输出**：
- 板块上涨的核心逻辑链（如"政策出台→订单放量→业绩兑现"、"技术突破→应用落地→商业化"）
- 逻辑链中需要验证的关键节点（哪些环节有数据支撑，哪些仍缺证据）

---

#### 1.2b-2 双假设证据收集

**搜索目标**：围绕逻辑链的关键节点，分别搜索支持逻辑和破坏逻辑的证据

**数据源**（按行业类型选择，通过 CDP 访问）：

**行业专业平台**（首选，用于获取价格/供需/开工率等硬数据）：
- 按第一步的行业类型，访问对应行业平台搜索：价格、开工率、装置动态、产能、出货量、进出口、库存等
- 关注行业平台的热点聚焦/周评/月评文章，这些是行业景气度的直接信号

**证券平台**（补充，用于获取机构观点和政策动态）：
- 政策/监管动态：`https://so.eastmoney.com/news/s?keyword={概念名称}+政策` 或 `{概念名称}+监管`
- 行业新闻：`https://so.eastmoney.com/news/s?keyword={概念名称}+出货量` / `渗透率` / `订单` / `产能`
- 龙头公司公告：巨潮资讯搜索板块龙头公司名，查看最新公告中的业务进展
- 机构调研：东财机构调研页面，查看板块龙头公司近期调研中的行业观点

**双假设判定**：

| 假设 | 判定标准 | 证据来源 |
|------|---------|---------|
| H_延续 | 政策持续加码、地方/企业跟进落地 | 政策新闻、行业新闻 |
| H_延续 | 订单/产能/渗透率等硬数据持续改善 | 行业数据新闻、龙头公告 |
| H_延续 | 核心催化事件有后续进展或升级 | 行业新闻、板块新闻 |
| H_中断 | 政策收紧、补贴退坡、监管加强 | 政策新闻、监管公告 |
| H_中断 | 硬数据与逻辑矛盾（如声称需求爆发但出货不及预期） | 行业数据新闻、龙头公告 |
| H_中断 | 核心催化事件被反转、证伪或淡化 | 行业新闻、板块新闻 |
| H_中断 | 板块龙头公司公告中否认或弱化相关业务 | 巨潮资讯龙头公告 |

---

#### 1.2b-3 逻辑判定与 1.2 得分调整

**判定前自检**（必须在写判定前完成）：
- [ ] 是否搜索了至少1个行业专业平台？（非东财/巨潮）
- [ ] 搜索记录是否完整？（每个平台、每个关键词、每个结果）
- [ ] "未发现"是否基于真实搜索行为？（不是"搜错平台"或"懒得搜"）
- 如果以上任一项为否，**不得判定逻辑状态**，必须先补充搜索。

综合 H_延续和 H_中断的证据权重和时效性，判定板块驱动逻辑的状态，并调整 1.2 的原始得分。

| 逻辑状态 | 判定条件 | 1.2 得分调整 |
|---------|---------|-------------|
| 逻辑坚实 | 支持证据充分且持续，破坏证据微弱或不存在 | 保持 +8~+10 |
| 逻辑尚可 | 有支持但存在部分质疑，核心逻辑未受根本挑战 | 保持 +4~+6 |
| 逻辑松动 | 出现实质性破坏证据，核心逻辑受到挑战 | 下调至 0~-4 |
| 逻辑破裂 | 驱动逻辑被证伪或严重质疑（如龙头公司否认、政策反转） | 下调至 -6~-10 |

**调整后 1.2 最终得分范围仍为 ±10，Layer 1 总分体系不变。**

## Layer 2：资金承接力（权重 35%）

### 2.1 龙虎榜买卖结构（P1，权重 15/35）

**搜索目标**：买入方是机构/深股通还是游资/散户

**数据源**：
- 东方财富龙虎榜明细：`https://data.eastmoney.com/stock/lhb,{日期},{代码}.html`
- 关注买入前5和卖出前5的席位类型

**双假设判定**：

| 假设 | 判定标准 | 得分 |
|------|---------|------|
| H_延续 | 深股通/沪股通净买入占比>30% | +8分 |
| H_延续 | 机构专用席位净买入>5000万 | +7分 |
| H_中断 | 买入方全部为游资/散户营业部（拉萨、东方财富系） | -8分 |
| H_中断 | 买入前5中无机构/深股通席位 | -7分 |
| 中性 | 机构和游资混合，无明显主导 | 0分 |

**席位类型识别**：
- **机构/外资**：深股通专用、沪股通专用、机构专用
- **一线游资**：知名营业部（如中金、中信系等）
- **散户集中**：东方财富拉萨系、华泰证券某些营业部
