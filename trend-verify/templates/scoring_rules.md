# 趋势验证评分规则

本文件定义三层验证的评分计算规则、乘数映射和特殊情况处理。

---

## 一、评分计算流程

### 1. 收集原始证据

按 `templates/verification_checklist.md` 的8个检查项，逐项填写双假设证据并打分。

### 2. 计算各层原始分

每个检查项有一个带符号的原始分（正=延续，负=中断）。

**Layer 1 原始分** = 1.1得分 + 1.2得分（含1.2b调整） + 1.3得分（范围 -40 到 +40）
**Layer 2 原始分** = 2.1得分 + 2.2得分 + 2.3得分（范围 -35 到 +35）
**Layer 3 原始分** = 3.1得分 + 3.2得分（范围 -25 到 +25）

**1.2b 条件调整说明**：当 1.2 判定为板块共振（得分 ≥ +6）时，触发 1.2b 概念板块趋势逻辑验证。1.2b 的逻辑判定结果直接调整 1.2 的原始得分（调整范围仍为 ±10），不新增独立权重。当 1.2 判定为独狼时，1.2b 不触发，1.2 保持原有得分。

### 3. 标准化到 0-100

```
标准化公式: layer_score = (raw + max_abs) / (2 × max_abs) × 100

其中 max_abs 是该层满分绝对值:
  Layer 1: 40
  Layer 2: 35
  Layer 3: 25
```

### 4. 计算验证总分

```
验证总分 = Layer1标准化分 × 40% + Layer2标准化分 × 35% + Layer3标准化分 × 25%
```

验证总分范围：0-100分。

---

## 二、催化剂坍塌覆盖规则

当 Layer 1 的 1.1（公司确认/否认）判定为 H_中断 ≤ -15分时，触发催化剂坍塌：

1. **Layer 1 直接锁定为最低区间**：标准化后按 0-25分 计算
2. **Layer 2 和 Layer 3 不再评估延续**：转为评估"下跌时的缓冲/加速因素"
   - Layer 2：资金承接差（机构在买 = 可能有人接盘 = 下跌有缓冲），资金全跑（加速下跌）
   - Layer 3：监管风险升级（停牌 = 下跌可能中断），无监管风险（下跌可能连续）
3. **最终得分上限为 34分**（乘数锁定 ×0.7）

**催化剂坍塌评分调整**：

| Layer 2 资金情况 | Layer 2 得分 | Layer 3 监管情况 | Layer 3 得分 |
|-----------------|-------------|-----------------|-------------|
| 深股通/机构大举买入（有接盘） | 40分 | 无监管风险 | 50分 |
| 游资主导，买卖混合 | 25分 | 有关注函 | 30分 |
| 全部游资/散户，无承接 | 10分 | 停牌核查 | 15分 |

## 三、乘数映射

| 验证得分 | 乘数 | 含义 | 对技术评分的影响 |
|---------|------|------|----------------|
| 75-100 | ×1.0 | 趋势有支撑 | 不调整 |
| 55-74 | ×0.9 | 信号混合 | 下调10% |
| 35-54 | ×0.8 | 趋势偏弱 | 下调20% |
| 0-34 | ×0.7 | 趋势大概率中断 | 下调30% |

**乘数应用**：

```
adjusted_score = round(technical_score × multiplier)
```

示例：
- 技术得分 38分 × 0.7 = 27分（偏空 → 明确看空区间）
- 技术得分 65分 × 0.9 = 59分（中性 → 偏空区间）
- 技术得分 82分 × 1.0 = 82分（偏多不变）

---

## 四、评级对照

调整后得分直接使用 stock-analysis 的评级标准：

| 调整后得分 | 评级 | 含义 |
|-----------|------|------|
| ≥90 | ⭐⭐⭐⭐⭐ 明确看多 | 五维共振+趋势验证通过 |
| 75-89 | ⭐⭐⭐⭐ 偏多 | 技术偏多，趋势基本确认 |
| 60-74 | ⭐⭐⭐ 中性 | 技术中性或趋势验证削弱 |
| 45-59 | ⭐⭐ 偏空 | 技术偏空或趋势验证显著削弱 |
| <45 | ⭐ 明确看空 | 技术看空+趋势大概率中断 |

## 五、评分示例

### 示例：002354 天娱数科（催化剂坍塌场景）

**Layer 1（催化剂持续性）**：
- 1.1 公司否认物理AI+世界杯：-20分
- 1.2 板块部分共振（物理AI概念有多只跟涨）：+6分
  - 1.2b 触发：板块逻辑验证发现产业趋势有政策持续加码，逻辑尚可，1.2 得分保持 +6
  - （若 1.2b 发现逻辑松动，如行业数据与叙事矛盾，则 1.2 可能被下调至 0~-4）
- 1.3 主题驱动（物理AI是产业趋势）：+10分
- **Layer 1 原始分：-4/40** → 标准化：(-4+40)/80×100 = 45分
- **但触发催化剂坍塌**：Layer 1 锁定为 25分

**Layer 2（资金承接力）**：
- 2.1 深股通净买入14791万+机构净买入4602万：+15分
- 2.2 太平洋证券净卖出7506万：-10分
- 2.3 板块资金流向未明确：0分
- **Layer 2 原始分：+5/35** → 标准化：(+5+35)/70×100 = 57分
- 催化剂坍塌下按"有接盘"调整：40分

**Layer 3（阻力清晰度）**：
- 3.1 历史案例（概念否认后普遍大幅回调）：-15分
- 3.2 无监管风险：+10分
- **Layer 3 原始分：-5/25** → 标准化：(-5+25)/50×100 = 40分
- 催化剂坍塌下按"无监管风险"调整：50分

**验证总分** = 25×40% + 40×35% + 50×25% = 10 + 14 + 12.5 = **36.5分**

**催化剂坍塌上限**：min(36.5, 34) = **34分**

**乘数**：×0.7

**技术评分调整**：38 × 0.7 = **27分**（明确看空）
